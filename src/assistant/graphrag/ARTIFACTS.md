# Указатель результатов

Все пути ниже относительны корню репозитория. Итоговые данные — **v3**.
Предыдущие эксперименты сохранены для истории, их метрики не следует смешивать с итогом.

| Файл в artifacts/ | Назначение |
|---|---|
| graph.json, communities.json, index_stats.json | Итоговый индекс полного корпуса и стоимость |
| eval_baseline.json, eval_local.json, eval_global.json, eval_agent.json | Итоговые summary и rows по 24 вопросам |
| eval_extraction.json | Оценка извлечения на 16 эталонных документах |
| llm_cache/ | 2024 сохранённых ответа на момент v3; необходимы для воспроизведения |
| comparison-v3.json | Сравнение до/после исправления ERP; итог в after |
| graph-run-metadata.json, v3-source-manifest.json | Происхождение результатов и исходный код |
| baseline-run-metadata.json | Отдельное происхождение baseline |
| validation-erp-v3.json | 164 теста и lint |
| reproducibility-v3.json | Чистый клон Colab, совпадение JSON с кешем |
| docker-validation.json | Docker: тесты, lint, индекс, оценки и отдельный свежий запрос |
| docker-api-smoke.json | Реальные HTTP/ERP-вызовы, подтверждение и чтение заказа |
| docker-final-status.json | Состояние трёх сервисов после восстановления |
| clean-docker-validation.json | Отдельный чистый клон Docker: команды и сравнение результатов |
| inventory-coverage-v3.json | 8 отсутствующих связей из 288 ожидаемых отношений состава |

experiments/v1-a588beb/, experiments/v2-fd5e9a9/ и каталоги v3-*-probe/ —
архивы промежуточных вариантов. comparison-v2.json относится к предыдущему этапу.
Файлы *-status.json и журналы прошлых запусков фиксируют состояние на момент
их создания, а не текущее состояние проекта. Например, docker_verified=false
в reproducibility-v3.json описывает проверку Colab, проведённую до Docker.

docker-startup.log, docker-resume.log, docker-recovery.log содержат неудачные
попытки. Итог восстановления — docker-final-status.json. Список причин и решений
есть в [DOCKER_VALIDATION.md](DOCKER_VALIDATION.md). Файлы с сериализованными
проверочными скриптами служат дополнительным доказательством, а не точкой запуска.

Исходная статистика индекса сохранена: cache_hits меняется при повторном прогоне.
В Docker-проверке статистика повторного запуска хранится отдельно. 74 отброшенных
элемента полного индекса и 7 на эталоне извлечения — разные наборы, не противоречие.
Поле dropped считает сущности и связи вместе; его нельзя подписывать как точное
число только отброшенных связей без дополнительного измерения.

Для отчёта используйте итоговые eval-файлы, index_stats.json и
[разбор примеров](RESULTS_ANALYSIS.md). Исторические результаты не удаляйте.
